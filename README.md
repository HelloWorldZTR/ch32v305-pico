# ch32v305-pico
CH32V305RBT6 dev board with raspberry pi pico pin compatibility.

See [the pin layout and alternate-function diagram](docs/pin-mode.md).

## CherryUSB / USBHS

The repository includes a direct copy of the CherryUSB implementation used by
ProShock 4. See [CherryUSB USBHS configuration](docs/cherryusb-usbhs.md) for
source attribution and MounRiver project setup.
